# AMC000 empty-file

**Severity:** info

The instruction file has no content.

## What it checks

~~~text
AMC000 empty-file (info)

The file is empty or contains only whitespace, so agents get no guidance from it.
Add the exact commands to build and test, a few conventions, and boundaries
(always / ask first / never), or delete the file.

Run `agent-md-caregiver --init` to print a recommended skeleton.
~~~

## Example

`AGENTS.md`:

~~~md

~~~

Finding:

~~~text
AGENTS.md:1:1  info  AMC000  Instruction file is empty
fix: Add build and test commands, conventions and boundaries, or delete the file.
~~~

## How to fix

Follow the `fix:` line of the finding, or see the end of the text above.

## How to suppress

- One line: put `<!-- amc-ignore-next-line -->` on the line before it.
- A whole rule: `--rule AMC000=off`, or `{ "rules": { "AMC000": "off" } }` in `.agentmdcaregiver.json`.
- Change its severity: `--rule AMC000=warn`.
