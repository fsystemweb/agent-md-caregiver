# AMC011 duplicate-instruction

**Severity:** info

The same instruction appears twice in one file.

## What it checks

~~~text
AMC011 duplicate-instruction (info)

The same line (ignoring list markers, case and trailing punctuation) appears twice in the
file. Repeats waste context and drift apart when only one copy is edited.

Headings, tables, quotes, code blocks and short lines (under four words) are not compared.

Fix: delete one copy. Suppress with `<!-- amc-ignore-next-line -->`.
~~~

## Example

`AGENTS.md`:

~~~md
# A

- Always run the tests before committing.
- Keep functions small.
- Always run the tests before committing.
~~~

In the repo: `package.json`: `{"scripts":{"test":"x"}}`.

Finding:

~~~text
AGENTS.md:5:1  info  AMC011  Same instruction as line 3
fix: Delete this line or line 3.
~~~

## How to fix

Follow the `fix:` line of the finding, or see the end of the text above.

## How to suppress

- One line: put `<!-- amc-ignore-next-line -->` on the line before it.
- A whole rule: `--rule AMC011=off`, or `{ "rules": { "AMC011": "off" } }` in `.agentmdcaregiver.json`.
- Change its severity: `--rule AMC011=warn`.
