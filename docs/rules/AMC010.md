# AMC010 legacy-filename

**Severity:** info

codex.md is a legacy name, or CLAUDE.md and AGENTS.md are diverging copies.

## What it checks

~~~text
AMC010 legacy-filename (info)

AGENTS.md is the shared name that most coding agents read. Two things are reported:

1. `codex.md`: a legacy name. Rename it to AGENTS.md, or merge it into the AGENTS.md next to it.
2. A CLAUDE.md that is a separate copy of the AGENTS.md next to it: it does not import it and
   shares three or more identical lines with it, so the two will drift apart. (A CLAUDE.md that
   does not import AGENTS.md at all is also reported as an error by AMC005.)

Fix: keep one source of truth in AGENTS.md and make CLAUDE.md just `@AGENTS.md` plus any
Claude-specific notes.
~~~

## Example

`codex.md`:

~~~md
# Project

- Test: `npm test`
~~~

In the repo: `package.json`: `{"scripts":{"test":"x"}}`.

Finding:

~~~text
codex.md:1:1  info  AMC010  `codex.md` is a legacy name; AGENTS.md is the shared one
fix: Rename it: `git mv codex.md AGENTS.md`.
~~~

## How to fix

Follow the `fix:` line of the finding, or see the end of the text above.

## How to suppress

- One line: put `<!-- amc-ignore-next-line -->` on the line before it.
- A whole rule: `--rule AMC010=off`, or `{ "rules": { "AMC010": "off" } }` in `.agentmdcaregiver.json`.
- Change its severity: `--rule AMC010=warn`.
