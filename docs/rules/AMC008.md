# AMC008 tree-dump

**Severity:** info

A big directory-tree listing goes stale and tells agents little.

## What it checks

~~~text
AMC008 tree-dump (info)

A pasted directory tree (the `├──` / `└──` kind, three or more lines) is out of date after
the next rename, and agents can list the directory themselves.

Fix: describe only the directories whose purpose is not obvious, one line each, e.g.
"`src/rules/`: one file per lint rule". Suppress with `<!-- amc-ignore-next-line -->`.
~~~

## Example

`AGENTS.md`:

~~~md
# A

```
src/
├── app/
│   ├── main.ts
│   └── util.ts
└── lib/
```
~~~

Finding:

~~~text
AGENTS.md:3:1  info  AMC008  Directory tree of 4 lines will go stale
fix: Replace it with one line per non-obvious directory, or link to the docs.
~~~

## How to fix

Follow the `fix:` line of the finding, or see the end of the text above.

## How to suppress

- One line: put `<!-- amc-ignore-next-line -->` on the line before it.
- A whole rule: `--rule AMC008=off`, or `{ "rules": { "AMC008": "off" } }` in `.agentmdcaregiver.json`.
- Change its severity: `--rule AMC008=warn`.
