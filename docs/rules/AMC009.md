# AMC009 missing-boundaries

**Severity:** info

No always / ask first / never section, or no rule about secrets.

## What it checks

~~~text
AMC009 missing-boundaries (info)

Good instruction files say what an agent may always do, must ask before doing, and must
never do. Two things are reported, for root files that have content and do not just import
another file:

1. No boundaries: no heading such as "Boundaries" or "Never", and no "Always:" / "Ask first:" /
   "Never:" lines.
2. No rule about secrets (secrets, credentials, API keys, tokens, passwords, .env).

Fix: add a section like
  ## Boundaries
  - Always: run the tests before committing.
  - Ask first: adding a dependency, deleting files.
  - Never: commit secrets.

This is advice, so it is info and never fails a run.
~~~

## Example

`AGENTS.md`:

~~~md
# A

- Test: `npm test`
~~~

In the repo: `package.json`: `{"scripts":{"test":"x"}}`.

Finding:

~~~text
AGENTS.md:1:1  info  AMC009  No boundaries: nothing says what agents may always do, must ask about, or must never do
fix: Add a "Boundaries" section with "Always:", "Ask first:" and "Never:" lines.
~~~

## How to fix

Follow the `fix:` line of the finding, or see the end of the text above.

## How to suppress

- One line: put `<!-- amc-ignore-next-line -->` on the line before it.
- A whole rule: `--rule AMC009=off`, or `{ "rules": { "AMC009": "off" } }` in `.agentmdcaregiver.json`.
- Change its severity: `--rule AMC009=warn`.
