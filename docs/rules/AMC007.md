# AMC007 too-long

**Severity:** warn

The file is longer than the line budget (default 150).

## What it checks

~~~text
AMC007 too-long (warn)

Instruction files are loaded into every conversation, so each line costs context and the
important ones get lost in a long file. The default budget is 150 lines.

Change the budget with `--max-lines <n>` or `"maxLines"` in .agentmdcaregiver.json,
or turn the rule off with `--rule AMC007=off`.

Fix: keep commands, conventions and boundaries here; move detail into docs and link it
(or import it with `@docs/file.md`).
~~~

## Example

`AGENTS.md`:

~~~md
# A

- Note 1: keep module 1 documented.
- Note 2: keep module 2 documented.
- Note 3: keep module 3 documented.
- Note 4: keep module 4 documented.
... (160 lines)
~~~

Finding:

~~~text
AGENTS.md:151:1  warn  AMC007  File is 162 lines, over the budget of 150
fix: Cut 12 lines: keep commands, conventions and boundaries, and link longer docs instead of inlining them.
~~~

## How to fix

Follow the `fix:` line of the finding, or see the end of the text above.

## How to suppress

- One line: put `<!-- amc-ignore-next-line -->` on the line before it.
- A whole rule: `--rule AMC007=off`, or `{ "rules": { "AMC007": "off" } }` in `.agentmdcaregiver.json`.
- Change its severity: `--rule AMC007=warn`.
