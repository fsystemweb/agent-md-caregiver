# Code of Conduct

We want this project to be welcoming to everyone.

- Be respectful and assume good intent.
- Give feedback on the work, not the person.
- No harassment, discrimination, or personal attacks.
- Maintainers may remove comments, issues or PRs that break these rules, and may block repeat offenders.

To report a problem, open an issue marked `conduct` or contact the maintainers privately through the email on their GitHub profile.

This is a short adaptation of the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
